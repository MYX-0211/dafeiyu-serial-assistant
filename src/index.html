使用说明

三种连接模式

  • 串口—— 下拉列表里直接选 COM 口，插拔设备会自动刷新。
  • TCP Client—— 作为客户端连接「远程 IP + 端口」。
  • TCP Server—— 用「本地」地址 + 端口在本机监听。本地地址建议选「全部网卡」，这样所有网卡都能连进来；若指定具体某张网卡，只有该网段能连。
  • UDP—— 用「本地」地址 + 端口绑定收包，往「远程 IP + 端口」发包（本地端口填 0 表示自动分配）。

接收区

  • 「分包显示」默认开启：超过设定超时（默认 20 ms）没有新数据就换行，便于分辨一帧一帧的数据。
  • 滚动条在底部时会自动跟随新数据；往上翻看历史时不会被打断，点右下角箭头可回到底部。
  • HEX 输入允许空格、逗号、0x 前缀，大小写不限。
  • 中文乱码？把接收区的「编码」从 UTF-8 切到 GBK —— Keil 工程里的中文字符串默认就是 GBK 编码。

多条字符串发送

  • 直接在右侧输入框里改内容，改完自动保存；输入框里按 Enter 直接发送。
  • 点每条后面的 ASC / HEX 标签，切换这一条按文本还是十六进制发送。
  • 「全部发送」按顺序发一遍；勾上「循环」按设定间隔轮流发送。

按键即发 / 回车发送

  • 按键即发：勾上后，在发送框里每敲一个字符就立刻发出去，输入框同时保留内容方便你看。和设备做终端式交互（比如敲 Shell 命令）时很顺手；退格键会发送 0x08。
  • 回车发送：勾上后，在发送框里按 Enter 直接发出当前内容并清空输入框；想换行用 Shift + Enter。
  • 两者可以同时开：边敲边发，回车补一个换行结束这一行。
  • 没勾选时，Enter 就是普通换行，用 Ctrl + Enter 发送。

快捷键

  • Ctrl + Enter 发送　Ctrl + K 清空接收区　Ctrl + Shift + L 清空发送框
  • Ctrl + 鼠标滚轮 调整接收区字号　Esc 关闭弹窗并停止定时 / 循环发送
  • 把文件拖到窗口上 = 按 256 字节分包发送该文件
